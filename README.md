# Awesome Claude Video Styles [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

[English](README.md) · [中文](README.zh.md)

**103 video styles** you can make with Claude (or any coding agent) — launch films, explainers, title sequences, memes, music videos — each with a sample and a long prompt you can copy. Named after the look they match: Linear-style launches, Kurzgesagt-style explainers, Star Wars-style crawls, Windows XP error memes.

Click any style for its sample and the prompt. Paste the prompt into Claude Code (or Codex, Cursor…) with your own content; optional: `npx skills add sunsiyuan/ultramotion` for the renderer and sound. All styles: **[ultramotion.ai/templates](https://ultramotion.ai/templates/?utm_source=github&utm_medium=readme&utm_campaign=awesome-claude-video-styles)**.
